# NEXVORA E-SPORTS Website

Static multi-page esports website:
- `index.html` — Home
- `roster.html` — Roster + player stats
- `matches.html` — Match center
- `media.html` — Media archive

## Update player stats
Edit the `PLAYERS` array in `js/app.js`:
- `role`
- `matches`
- `tournamentKills`
- `scrimKills`
- `totalKills`

Replace the placeholder match/media content in `js/app.js` / `media.html` as official information becomes available.

The supplied NEXVORA logo is included at `assets/nexvora-logo.png`.
